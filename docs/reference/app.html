App and APIs

All endpoints are read-only JSON. Through the portal, prefix membership routes with /api/membership and bed routes with /api/capacity.

membership-api#

RouteReturns
GET /api/membersPaged members. Filters: status (paid, due, unpaid, notpaid), segment, class, province, q; sort, page, pageSize (max 200)
GET /api/members/{13-digit id}One member with contribution breakdown and payment history
GET /api/payments/summaryTotals and collection rate by segment, class and province
GET /api/metaSegments, class fees, due day and other rule constants
RuleValue
Classes 1, 2, 3IDR 150,000, 100,000, 42,000 per member per month (class 3 includes IDR 7,000 government subsidy)
Wage earners5% of salary (4% employer, 1% employee), salary capped at IDR 12,000,000
Subsidized membersIDR 42,000 paid by the government
Due dateThe 10th of each month; after that, unpaid months put the member in arrears and coverage is inactive

bed-api#

RouteReturns
GET /api/hospitalsHospitals with beds per class. Filters: province, city, class, available=1, q
GET /api/hospitals/{RS-XXX-NN}One hospital
GET /api/beds/summaryCapacity and availability per class across hospitals
GET /api/beds/classesThe nine bed classes

portal#

RouteReturns
GET /The web UI
GET /api/infoVersion, region, cluster and pod serving the request
GET /api/membership/*, /api/capacity/*Proxied to the two APIs

Operational endpoints#

Every service exposes /healthz (liveness), /readyz (readiness) and /metrics (Prometheus text format). Setting FAULT_RATE (0 to 1) makes that fraction of API calls fail with HTTP 503, which the demo uses to fire an alert.
